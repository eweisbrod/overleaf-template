# Overleaf paper template

A LaTeX manuscript template demonstrating the table and figure outputs of the companion [`project-template`](https://github.com/eweisbrod/project-template), with citation, hypothesis-numbering, and section-structure examples. Built to work on Overleaf for real-time multi-author editing.

> 📖 **Reproducible-research conventions, pedagogical context, and in-depth topic chapters** (project structure, Git/GitHub, environment variables, IDE setup, the JAR Data Policy, AGENTS.md, …) live at the companion hub site: <https://eweisbrod.github.io/example-project/>

> **This is a template.** Click "Use this template" on GitHub to create your own paper repo, or import directly into Overleaf via *New Project → Import from GitHub*.

## What's here

- **`main.tex`** — the main manuscript with section scaffolding (Intro, Literature Review, Data, Empirical Strategy, Results, Conclusion), citation examples, hypothesis numbering, and equation numbering.
- **`Bibliography.bib`** — example BibTeX entries.
- **`figures/`** — placeholder figures referenced from `main.tex`. Replace with your own pipeline outputs (or `\input{}` `.tex` files from `project-template`'s `OUTPUT_DIR`).
- **`AGENTS.md`** / **`CLAUDE.md`** — AI-assistant context files (see the [About AGENTS.md](https://eweisbrod.github.io/example-project/topics/agents-md/) topic on the hub).

## How to use

1. Click **Use this template → Create a new repository** to spin up your own copy.
2. Either clone the new repo locally and edit `main.tex` with a LaTeX editor of your choice, **or** import the repo into Overleaf via *New Project → Import from GitHub* for browser-based multi-author editing.
3. Replace the placeholder body content of `main.tex` with your own writing.
4. Drop the `.tex` table files and figures generated by your `project-template` pipeline's `OUTPUT_DIR` into the repo and `\input{}` them from `main.tex`. The two templates are designed to slot together at the `.tex`-file boundary.
